Aquí hay 20 historias de usuario para la aplicación MarinoGPS, escritas siguiendo el principio INVEST:

**Prioridad Alta:**

1. Como navegante, quiero poder ver mi ubicación actual en un mapa preciso para saber dónde estoy.
2. Como navegante, quiero poder marcar waypoints para guardar lugares importantes en mis rutas de navegación.
3. Como planificador de rutas, quiero poder crear y guardar rutas para mis viajes, incluyendo puntos intermedios.
4. Como navegante, quiero ver mapas náuticos detallados con información de profundidades, boyas y peligros para navegar de forma segura.
5. Como navegante, quiero descargar mapas offline para poder usar la aplicación incluso sin conexión a internet.
6. Como usuario, quiero recibir alertas en tiempo real sobre cambios en las condiciones meteorológicas que podrían afectar mi seguridad.
7. Como usuario, quiero ver pronósticos meteorológicos precisos, incluyendo viento, olas y temperatura, para planificar mis viajes.
8. Como usuario, quiero poder compartir mi ubicación en tiempo real con mis contactos para que sepan dónde estoy.
9. Como usuario, quiero una interfaz intuitiva y fácil de usar para poder acceder rápidamente a la información que necesito.
10. Como usuario, quiero una brújula digital precisa que me indique mi rumbo.


**Prioridad Media:**

11. Como usuario con sensores NMEA 2000, quiero poder integrar mi aplicación con mis sensores para ver datos de velocidad, profundidad y rumbo en tiempo real.
12. Como usuario, quiero poder configurar alertas personalizadas para avisarme cuando me acerque a zonas de peligro o me desvíe de mi ruta.
13. Como usuario, quiero registrar mis rutas en un historial para poder revisarlos más tarde.
14. Como usuario, quiero poder exportar mis registros de rutas en un formato común como CSV o KML.
15. Como usuario, quiero poder buscar lugares de interés marinos, como puertos o puntos de amarre, en el mapa.


**Prioridad Baja:**

16. Como usuario, quiero poder comunicarme con otros usuarios de la aplicación a través de un chat o foro.
17. Como usuario, quiero una función de realidad aumentada que me permita ver información superpuesta en la imagen de mi cámara.
18. Como usuario, quiero poder reservar amarres directamente desde la aplicación.
19. Como usuario, quiero poder buscar y alquilar embarcaciones a través de la aplicación.
20. Como usuario, quiero que la aplicación esté disponible en varios idiomas.


Estas historias de usuario son independientes, negociables, valiosas, estimables, pequeñas y comprobables (INVEST), y cubren las necesidades principales de los usuarios de la aplicación MarinoGPS.  Se priorizan según la importancia para el lanzamiento mínimo viable del producto.  La priorización y el detalle se pueden ajustar a lo largo del desarrollo del producto.
